Run this only in Test/Calibration mode, robot on the ground (NOT elevated - that's the separate rotation PID autotune). Keep the test area clear.

Setup

Mark the robot's front and a matching mark on the floor. Pick a whole number of rotations and a speed, then press Run. The robot spins that many full turns; you eyeball how far off the marks ended up.

Enter result

Robot stopped. Check the marks: if the robot undershot, enter a negative residual angle; if it overshot, enter a positive one.

Reset robot

Physically re-align the robot to its starting orientation, then click Ready.
